# Warpath — тактический помощник

Автоматизация Warpath в LDPlayer под Windows. Python управляет игрой через локальный ADB; интерфейс написан на Rust/egui. Мятовая тема, анимированные персонажи, контроль этапов и статистика операций.

## Установка и запуск

1. Установите Python 3.14, Rust с Cargo и средствами сборки MSVC, LDPlayer 9.
2. Выполните `python -m pip install -r requirements.txt`.
3. Запустите `build.bat`, затем `start.bat`. Сборка создаёт `warpath-helper.exe` в корне.
4. В LDPlayer включите локальную отладку ADB; откройте Warpath на русском, разрешение Android 1920×1080.
5. Настройте сборщиков и производство, затем нажмите «Запустить автоферму».

Текущие пути по умолчанию: LDPlayer `C:/LDPlayer/LDPlayer9`, ADB `127.0.0.1:5555`, Python `%LOCALAPPDATA%/Programs/Python/Python314/python.exe`. При другой установке измените пути в bot.py, worker.py и native-ui/src/main.rs. Для OCR нужны Windows PowerShell и русский язык распознавания Windows.

## Возможности

- Помощь всем участникам альянса, пожертвования от одного доступного участия с приоритетом рекомендованных технологий.
- Вызов воздушных поставок и сбор распознанных ящиков; получение наград радара.
- Пять сборщиков, готовые схемы распределения, поиск максимального доступного уровня месторождения.
- Производственные последовательности четырёх мастерских, дополнение свободных мест, получение готовых материалов.
- Личные исследования, пополнение войск, опциональное вступление в групповые атаки.
- Ежедневные действия и миссии офицеров; отдельный запуск наземной и морской кампании.
- Проверка возврата на карту между этапами, повтор после сбоя, закрытие распознанных рекламных предложений.
- Статистика отправок, уровней, прочитанной добычи и производства. Подробности — [СТАТИСТИКА.md](СТАТИСТИКА.md).
- Скрытие окна LDPlayer при сохранении работы эмулятора.

## Ограничения

Проект тестовый: распознавание зависит от языка, разрешения и интерфейса игры. Все виды заданий и неизвестные окна не поддержаны. Кампания ограничена распознаваемыми целями. Автоматический аварийный перенос базы не завершён. Адаптер пазла включается только после отдельной калибровки; готового профиля Warpath нет. DeepSeek используется при восстановлении, ключ вводится локально и защищается средствами Windows.

Не нажимайте вручную в игре во время прохода. «Стоп» отменяет дальнейшие команды; уже отправленные игровые приказы могут завершиться. Старые очереди и рейсы до начала учёта не восстанавливаются в статистике задним числом.

## Проверки и данные

`python -X utf8 -m unittest discover`

`cargo test --manifest-path native-ui/Cargo.toml`

В репозиторий включены очищенные изображения для распознавания и регрессионных тестов. Они сохраняют необходимые игровые области, но не являются журналом текущего аккаунта. Личные схемы, ключи, координаты, статистика и журналы создаются локально и исключены через .gitignore.
